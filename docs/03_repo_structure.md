## Repo Structure

The repo basic structure:

- `config/` central project settings
- `docs/` path to documentation
- `sample_data/` multiple CSV raw data files
- `sql/` reusable setup and governance SQL
- `src/` reusable Python transformation logic
- `notebooks/` notebook tasks
- `.github/workflows/` repository checks

In the project root folder, the file `databricks.yml` defines this project`s bundle.
